# Banking_EDA_Project
This project is an end-to-end Data Analytics solution built using SQL, Python, and Power BI. It focuses on analyzing banking customer data to generate meaningful business insights related to customer demographics, relationships, and investment behaviour.
The project involves data cleaning, transformation, and visualization to support data-driven decision-making.

##  Problem Statement
**Develop a basic understanding of risk analytics  in banking and financial services and unserstan how data is used  to minimize the risk of losing money while** **lending to customers.**

The raw banking dataset contained:
- Duplicate Client IDs
- Encoding issues in column names
- Multiple relational tables requiring joins
- Inconsistent data structure

The goal was to:
- Clean and preprocess the data
- Ensure unique customer identification
- Build a unified dataset
- Create an interactive dashboard for insights


## Tools & Technologies
- **SQL (MySQL)** – Data cleaning & transformation
- **Python (Pandas, Matplotlib, Seaborn)** – Exploratory Data Analysis
- **Power BI** – Dashboard creation & visualization
